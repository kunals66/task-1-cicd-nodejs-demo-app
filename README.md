# Task 1 - CI/CD Pipeline Using GitHub Actions

## Objective

Automate the build and testing process of a Node.js web application using GitHub Actions.

## Tools Used

- GitHub
- GitHub Actions
- Node.js
- Docker

## Workflow

1. Push code to main branch
2. GitHub Actions runs automatically
3. Install dependencies
4. Run tests

## Project Structure

- server.js
- package.json
- Dockerfile
- .github/workflows/main.yml

## Outcome

Successfully implemented a CI/CD pipeline for a Node.js application.
